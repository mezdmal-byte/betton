# Обеспечение LMSR

Для новых событий глубина определяется реальным залогом и начальными ценами:

`b = lock_ton / ln(1 / min(p_initial))`.

При равных вероятностях `min(p_initial) = 1/n`, поэтому остаётся
`b = lock_ton / ln(n)`. При неравных вероятностях за тот же залог глубина меньше,
а цены сильнее реагируют на ставки. Стартовые вероятности сохраняются.

## Почему банк покрывает выплаты

Пусть q0 — начальный вектор, x — выпущенные игрокам доли.
Банк после покупок равен `lock_ton + C(q0 + x) - C(q0)`.
Для любого победившего исхода i требуется x_i TON.
Из `C(q0+x) >= q0_i+x_i` следует:

`банк - x_i >= lock_ton + q0_i - C(q0)`.

Поэтому достаточно `lock_ton >= C(q0) - min(q0)`.
При `q0_i = b*ln(p_i)` это `b*ln(1/min(p_i))`.
Код вычисляет коэффициент риска из того же нормализованного начального вектора,
что используется при создании рынка, включая существующее ограничение малых вероятностей.

## Старые события

Нет миграции b, цен, долей или балансов. Перед покупкой под блокировкой рынка
проверяются обязательства по каждому исходу после покупки: они не должны
превысить банк после оплаты. Та же проверка есть в предварительной котировке.
Непокрытая покупка получает 409 без списания баланса и выдачи долей.

Уже возникший дефицит этим не пополняется. Если расчёт старого события требует
больше средств, чем есть в банке, сохраняется полный откат с 409.
Для таких событий потребуется отдельное решение о фактическом пополнении банка;
автоматического списания со счетов и сокращения выигрыша нет.

## Проверка

`python -m pytest -q tests` — 69 passed на изолированной SQLite.
Новые тесты включают залог 50 TON / старт 90:10 / ставку 100 TON на редкий исход,
выплаты по каждому исходу трёхисходного события, последовательности крупных
покупок, равномерный старт на восьми исходах и отказ старого рынка без изменения
баланса, долей, банка и сделок.

В app/lmsr.py изменено только вычисление ln(exp(t)-1) при больших t:
`t + ln(1-exp(-t))`. Это тождественная форма без переполнения exp(t).
Стоимость C(q), softmax, цена 1/p, номинал доли и чаевые не менялись.
