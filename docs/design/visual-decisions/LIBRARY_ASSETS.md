# BETTON · Visual v1 — оригинальные PNG без ZIP

**Источник оригинальных изображений:** ChatGPT Library, папка **`/BetTON/Visual References v1`**.  
**Проверено:** в Library лежат **10 полноразмерных PNG + `MANIFEST.json`**, все поимённо доступны. ZIP скачивать НЕ НУЖНО.

## Как открыть изображения в Work

1. Открой список файлов/Library через доступный Work/Files-инструмент, найдя папку `/BetTON/Visual References v1`. Если у Work есть доступ к файлам этой Project-сессии, используй Library search/list и прочитай изображения по именам.
2. Важно: папка **не является GitHub-папкой**. Сейчас GitHub PR #29 содержит текстовую спецификацию и один уменьшенный превью-файл, а **полные исходники живут в ChatGPT Library**. Не обещать, что полный PNG есть в GitHub, пока действительно не проверена загрузка.
3. При работе в Figma используй оригинальные PNG только как референсы на отдельной странице `REFERENCES`; итоговые экраны собирай из **редактируемых Figma-слоёв**, а не из вставленных скриншотов. Если Work не видит Library, не выдавай отсутствие референсов за их наличие: используй приложенный к проекту файл или попроси добавить PNG через библиотеку.
4. Имея доступ к файлам и GitHub-записи, можно дополнительно загрузить исходные картинки в GitHub `docs/design/visual-decisions/assets/`; но **это не должно задерживать Figma-вёрстку**. Доступных исходников в ChatGPT Library уже достаточно для работы.
