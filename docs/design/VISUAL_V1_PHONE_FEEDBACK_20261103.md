## Реальные исправления

- FEED сохраняет существующую компактную геометрию и на высоких viewport. Шапка/низ ленты — 52/64 px. На 390×844 и 430×844 теперь четыре полных события вместо трёх. На 320×844 остаются три; на коротких высотах новый прирост не заявляется. Заголовок, дата, оба исхода и все три показателя сохранены; масштабирования страницы нет.
- Drawer фиксирует ось после начала движения, допускает последующее отклонение пальца. Закрывающая анимация проходит расстояние всей панели. Компактную ставку можно тянуть вверх за всю область; вниз — сворачивать.
- Оба исхода доступны внутри быстрой ставки и своего коэффициента. У каждого исхода свой черновик, сохраняющийся при переключении режима и полном закрытии/открытии формы. Проверен сценарий 1,74 → второй исход 2,10 → свой 2,30 → первый 1,74 → закрытие/открытие → второй 2,30.
- При фокусе обсуждения закреплённая ставка скрывается. Composer растёт до 112 px. Для touch текстовые поля имеют минимум 16 CSS px, дублирующая подсветка текстовых полей убрана; клавиатурный фокус кнопок сохранён. Встроенный чат ограничен пятью сообщениями, есть полная страница обсуждения.
- Правила, даты, способ проверки и критерии находятся во вкладке «Информация». Согласование сворачивается отдельной кнопкой; нажатие заголовка его не закрывает. Показаны текущий этап, подтверждённая редакция и следующий шаг. История преобразует snapshots в понятный текст вместо JSON/Unicode escape.
- Устранён замкнутый круг `collecting`: UI раньше блокировал ставки, необходимые backend для формирования фонда. Формы теперь доступны при серверном consent в `collecting`/`active`, кроме гаранта собственного события. Суммы, обеспечение, комиссии и активация остаются серверным контрактом; matching/settlement не менялись.
- Известные ошибки заполнения события показываются конкретно вместо «Некорректный запрос». Валидное создание с гарантом проверено; причина ошибки конкретной пользовательской сборки не подтверждена.
- Десктопная дата вызывает native showPicker; значение управляемого поля проверено. Внешний вид календаря ОС не заснят.

## SIM

Добавлены 13 публичных сценариев, один содержит 200 первоначальных тестовых заявок и 159 фактических исполнений через существующий P2P. Шесть уровней цены, 13 полностью сверенных журналов; повторный запуск не создаёт новых операций, общий объём средств и балансы остальных пользователей сохраняются. Шесть автоматических гарантов и прежние сценарии сохранены.

История действительно новая, без искусственного переноса сделок в прошлое. SQLite хранит время до секунды, поэтому есть совпадающие точки. Существующий API графика отдаёт последние 100 из 159 исполнений; 1 ч/24 ч сначала содержат одни и те же недавние сделки. Длительная историческая выборка этим не проверена.

Для существующего поколения: `scripts/enrich_simulation.py`, `enrich-betton-simulation.bat`, `enrich-telegram-simulation.bat`. Требуются распознанная полная SIM и остановленный launcher; перед дополнением создаётся проверенная SQLite backup-копия. Active pointer и старая история не сбрасываются. Совместимость старых описаний проверена отдельно: IDs и количества market/order/fill/ledger сохранились; новые описания человекочитаемы.

[Инструкция](../UPDATE_VISUAL_V1_TEST_20261102.md). На компьютере пользователя CLI/.bat не запускались, Windows lock на его устройстве не проверен. Для интерфейса нужен новый frontend build; enrich его не пересобирает.

Legacy UI и существующая SIM сохранены. Backend settlement, production DB, реальные деньги, webhook и основной Telegram-бот не менялись. Merge/deploy не выполнялись; запущенная пользователем Telegram-версия здесь не обновлялась. Выбор скрытия навигации и визуальное принятие владельцем остаются отдельными решениями.
