## Реальные изменения

| До | После | Основание / ограничение проверки |
|---|---|---|
| Только `expand()`, нет запроса fullscreen | V1 запрашивает fullscreen один раз, только при наличии initData, метода и поддержки API 8.0; ошибки и отказ не ломают обычный режим | `frontend/src/telegram/viewport.ts`; unit-тесты host-модели, не проверка Telegram |
| Одна ошибка bridge прерывает оставшиеся вызовы запуска | `ready`, `expand`, настройка свайпов защищены независимо | `webapp.test.ts` |
| Нет общей обработки system/content safe area | Один внешний безопасный прямоугольник для V1, фиксированные панели ограничены его внутренним контейнером | CSS и TypeScript собраны; геометрия на устройстве не принята |
| Высота оболочки не учитывает клавиатуру через visualViewport | Стабильная высота хоста; при редактировании и уменьшении видимой области — доступная высота над клавиатурой | Unit-модель resize/focus; клавиатура iOS/Android не проверена |
| Шапка ленты 78 px, в том числе верхний отступ 28 px | В Telegram 56 px; при доступной высоте менее 700 px — 52 px | Адаптация существующей композиции, без изменения карточек |
| Навигация 80 px независимо от высоты | Компактный вариант 64 px, обычный вариант сохранён | Не измерено число реально видимых карточек |
| Ширина drawer зависит от всего browser viewport | Ширина зависит от контейнера приложения, включая его безопасные отступы | Нужна браузерная проверка узкого экрана и Desktop |
| Меню без собственного Telegram Back и полного возврата фокуса | Back закрывает меню; Tab удерживается внутри; после закрытия фокус возвращается; обновление callback не сбрасывает фокус | Статическая проверка, существующие Back ownership unit-тесты; живой keyboard/swipe QA не выполнен |
| Отказ гаранта доступен только во входящем приглашении | В согласовании назначенный гарант получает вход в существующее подтверждение отказа; возврат ведёт в согласование | Сервер уже допускает отказ в `review`; policy и markup-тесты |

Расчёт выигрыша высоты **только по CSS**, не результат измерения WebView:
прежняя оболочка ленты `78 + 80 = 158 px`, компактная `52 + 64 = 116 px`,
разница `158 − 116 = 42 px`. Безопасные отступы, категории и фильтры в расчёт не входят.
В большом Telegram-окне шапка и навигация дают `56 + 80 = 136 px`.
Всё приложение не масштабируется. Высота карточек и их типографика этим пакетом не менялись.

Legacy доступен через `?ui=legacy`; новый viewport-сервис и новая обёртка включаются только для V1.
Общая boot-функция изменилась только в части независимой обработки ошибок bridge.

## Блокеры и снимки

1. Локальный Vite успешно запущен на loopback. При попытке открыть preview облачный браузер
   отклонил действие: URL policy не выдала authority на наблюдение. Обход не выполнялся.
2. До этого установка локального Playwright Chromium вернула повреждённый/пустой ZIP;
   установленного локального браузера нет. Playwright не объявляется запущенным локально.
3. Свежих снимков React «до/после» **нет**. Старые `docs/design/visual-v1-qa/` не выдаются за новые.
4. Доступа к `C:\Users\1\betton-v1-test`, мобильному Telegram и Telegram Desktop нет.
   Не проверены настоящие safe area, bridge, keyboard, свайпы, client-specific fullscreen denial.
5. Оригинал онбординга доступен, но новая композиция не переносилась без возможности
   проверять результат глазами. Качество изображений, схем и центрирование остаются открытыми.

Draft PR и успешная сборка не разрешают merge/deploy. После публикации надо смотреть CI
именно текущего HEAD; заранее зелёный CI в этом документе не заявляется.
