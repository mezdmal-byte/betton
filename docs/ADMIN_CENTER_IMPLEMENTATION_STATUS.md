# Admin Center — implementation status (2026-10-23)

Status: **standalone local read-only implementation**, transferred from the verified `BetTON_Admin_Center_v1_local.zip` and hardened in `feature/admin-center-readonly-v1`. No deployment or merge to main.

## Implemented

- `admin_center/app.py`: separate FastAPI app; protected read-only users, events, orders, fills, settlements, ledger list/detail endpoints; bounded IDs and pagination; no business-app import.
- `admin_center/store.py`: reflected, allowlisted projections of the existing schema. SQLite native `mode=ro` + query-only; SQL read guard. Local test/sandbox PostgreSQL support with read-only transactions, timeout and role checks (not server-tested here).
- `admin_center/security.py`: separate PBKDF2 / HTTP Basic identity, server-side authorization on all routes/assets, loopback/Host/proxy/cross-site restrictions, brute-force limit and response headers.
- `admin_center/static/`: desktop shell based on Figma v1 palette/layout; actual configured DB data, ID searches, filters, related-object links and browser Back. Unconnected monitoring sources are explicitly unavailable, never synthetic healthy states.
- `admin_center/launcher.py`, `setup-admin-center.bat`, `start-admin-center.bat`: isolated dependencies, interactive local SQLite configuration, password hashing, no-server `--check`, fixed loopback listener, no proxy trust or access logs.
- Russian runbook: [ADMIN_CENTER_README_RU.md](../ADMIN_CENTER_README_RU.md).
