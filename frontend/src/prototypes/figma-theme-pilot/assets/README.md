# Pilot assets

SVG files are unmodified native Figma SVG exports from file
`GRbVHwppYxx5c7N5WG1BVA`, comparison frames `57:8` and `58:178`.
The short-lived URLs returned by design context were unavailable from the
execution environment, so the same nodes were exported read-only with
`exportAsync({ format: 'SVG_STRING' })`. No canvas nodes were changed.

The SVG alpha geometry is used as a CSS mask. Colors come from semantic
tokens; no SVG paths are redrawn or edited. The original exported stroke
extents are preserved in the 56 × 18 and 358 × 58 Figma layout slots.

Inter 3.19 WOFF2, weights 400/500/600/700/800, is self-hosted from the
[official Inter repository](https://github.com/rsms/inter/tree/v3.19/docs/font-files).
The included OFL.txt is the original
[license](https://github.com/rsms/inter/blob/v3.19/LICENSE.txt).
Its text metrics match the reference measurements more closely than Inter 4.1.
